The `schemaport probe` command sends compiled tool definitions to provider APIs for validation. It reports one of four verdicts: accepted, rejected, error, or skipped. The command requires credentials and makes a network request. The `--targets` flag specifies which providers to probe, and the `--format` flag determines the output format. The `--model` flag allows specifying a particular model for probing. The command exits with a code indicating the outcome: 0 for success, 1 for a rejection or refused compilation, and 3 for an error. The `probe` command is used to validate tool definitions against provider APIs, and its exit codes provide information about the outcome.
